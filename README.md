# منصة المُنجِز الأكاديمي (Acad Solver Web) — جاهزة للنشر على Vercel

تطبيق ويب مبني بـ **Next.js (App Router) + TypeScript + Tailwind CSS + Vercel Blob** لاستقبال طلبات الأنشطة والتمارين الجامعية من الطلبة، ومراجعتها من لوحة تحكم المشرف، وتوليد الحلول بالذكاء الاصطناعي (Gemini) بالاعتماد الحصري على مراجع المقياس المرفوعة، ثم تصديرها في ملفات **Word (.docx)** عربية من اليمين إلى اليسار (**RTL**) مع جداول RTL ومعادلات Word أصلية (**OMML / Cambria Math**).

## المميزات الأساسية
- **بوابة الطالب (`/`)**: إرسال الطلب، رفع ملفات التمرين ومراجع المقياس (PDF/صور/نصوص)، خيار بدون واجهة جامعية (دخول مباشر في الحل)، والحصول على رمز تتبع فوري.
- **صفحة تتبع الطلب (`/track`)**: متابعة حالة الطلب (قيد الانتظار → قيد المراجعة → مكتمل)، معاينة الحل المعتمد بمعادلات KaTeX، وتحميل ملف `.docx` جاهز للرفع. يتوفر طلب تجريبي جاهز برمز `UFC-2026-1001`.
- **لوحة تحكم الإدارة (`/admin`)**: محمية بكلمة مرور، تتيح استعراض الطلبات والملفات المرفوعة، توليد مسودة الحل بـ Gemini API، تحرير الكتل والجداول والمعادلات، معاينة وتحميل ملف Word قبل الاعتماد، ثم اعتماد التسليم للطالب.
- **تخزين دائم على Vercel (`@vercel/blob`)**: عند تفعيل Vercel Blob من لوحة Vercel (مجاني)، تُحفظ جميع الطلبات وملفات الطلبة بشكل دائم ومباشر عبر `BLOB_READ_WRITE_TOKEN`، بينما يعمل محليا تلقائيا عبر مجلد `.data/`.

## خطوات النشر المجاني على Vercel
1. ارفع مجلد `acad-solver-web` إلى مستودع GitHub خاص أو عام.
2. ادخل إلى [vercel.com/new](https://vercel.com/new) واختر المستودع (سيكتشف Vercel إعدادات Next.js و`vercel.json` تلقائيا).
3. من قسم **Environment Variables** في المشروع أضف:
   - `GEMINI_API_KEY`: مفتاح Gemini API (مجاني من [Google AI Studio](https://aistudio.google.com/apikey)).
   - `ADMIN_PASSWORD`: كلمة المرور التي تختارها للوحة الإدارة `/admin`.
4. من تبويب **Storage** داخل مشروعك على Vercel اضغط **Create Database → Blob** واربطه بالمشروع (يضيف تلقائيا متغير `BLOB_READ_WRITE_TOKEN` لحفظ الطلبات والملفات المرفوعة بشكل دائم).
5. أعد النشر (Redeploy) وسيصبح التطبيق متاحا مباشرة لطلبتك على رابط `https://your-project.vercel.app`.

## التشغيل المحلي
```bash
copy .env.local.example .env.local
npm install
npm run dev
```
ثم افتح `http://localhost:3000` لبوابة الطالب، و`http://localhost:3000/admin` للوحة التحكم.
